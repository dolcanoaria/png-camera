# 透過PNGカメラ

好きな透過PNGをカメラ映像や背景写真に重ね、合成写真をJPEGで保存するWebアプリです。

**現行版 v1.4.21** · [透過PNGカメラを開く](https://dolcanoaria.github.io/png-camera/)

「構図合わせ」は、Pixel 10aのChrome（Web版・インストール版）とiPad miniで動作確認済みです。

## カメラで撮影する

1. **背面カメラを起動**を押し、カメラの使用を許可します。
2. **カメラズーム**で背景の構図を調整します。PNGを追加する前から使える1〜4倍のデジタルズームです。
3. **透過PNGを追加**、または作品別ライブラリの**選択したキャラを追加**から、最大3枚まで配置できます。
4. キャラをタップするか、**操作するキャラ**の一覧から選びます。1本指で移動し、2本指で拡大・縮小・回転できます。**一番手前へ**・**一番奥へ**で重なり順を変更できます。
5. **合成写真を保存**を押します。JPEGの長辺は最大1920ピクセルで、選択枠は保存写真に入りません。

## 作品画像と構図を合わせる

1. 背面カメラを起動し、**構図合わせ用の画像を選ぶ**から作品画像を選びます。
2. 作品画像がライブ映像に50%で重なります。窓枠や建物の角を目印に、カメラの向きやズームを調整します。縦横比が異なる画像は中央を基準に表示し、画面からはみ出す部分を切り取ります。
3. 合ったら**構図合わせをオフ**にして撮影できます。オンのままでも、保存されるのはライブ映像と配置したPNGです。

## 背景写真に合成する

**背景写真を選ぶ**から端末内の写真を開きます。ライブカメラは停止し、選んだ写真が背景になります。PNGを配置して**合成写真を保存**を押すと、新しいJPEGを保存できます。元の写真はそのままです。ライブ撮影に戻るには**背面カメラを起動**を押します。

## 切り抜きと作品別ライブラリ

- **切り抜く写真・画像を選ぶ**から元画像を開きます。AIを使う場合は**AI用に対象を囲む**、**AIで切り抜く（オンライン）**の順に操作します。AI処理は端末内で行い、ライブラリとモデルの取得にはインターネット接続が必要です。
- **囲んで透明化**は、囲みの内側で背景と判断した色を消します。自動判定が難しい場合は、囲みの内側に残った背景色をタップします。消えた部分は**囲んで復元**で元画像から戻せます。細かい作業では最大400%まで拡大し、**表示位置を移動**で枠からはみ出した部分を表示できます。編集は**1つ戻す**で取り消せます。
- 結果は**透過PNGを保存**するか、作品名とキャラクター名を入力して**作品別ライブラリに登録**できます。
- 手持ちのPNGは**作品別フォルダをまとめて取り込む**、または作品名を入力して**この作品にPNGを登録**から追加できます。画像と一覧は利用中のブラウザやウェブアプリの端末内データに保存されます。サイトデータを消すと登録内容が失われるため、必要なPNGは別途保管してください。

## ホーム画面に追加・オフラインで使う

- **PixelのChrome**では、公開ページを開き、メニューから**アプリをインストール**または**ホーム画面に追加**を選びます。
- **iPad miniのSafari**では、共有メニューから**ホーム画面に追加**を選びます。**ウェブアプリとして開く**が表示されたらオンにして**追加**を押します。
- オンラインで一度開いて**オフライン準備完了**を確認すると、通信がない場所でも起動・撮影・写真合成ができます。AI切り抜きにはオンライン接続が必要です。

## GitHub Pagesで公開・更新する

ビルドは不要です。初回公開では、リポジトリのHTML、CSS、JavaScript、`manifest.webmanifest` と `icons/` を、フォルダー構成を保ったまま公開します。GitHub Pagesの公開元を `main` の `/(root)` に設定し、HTTPSのURLで開きます。

既存の公開先を更新するときは、更新ZIPのファイルを同じ場所に上書きします。v1.4.19からv1.4.20への差分は、ルートの `camera.js` と `sw.js` です。アプリの公開ファイルを変更したら `sw.js` のキャッシュ名を更新し、公開反映後に端末をオンラインにしてページを開き直してください。
